# 🐍 Python Fundamentals Project

## 📖 Overview

This project was completed during a **Data Technician Bootcamp** as part of my introduction to Python programming. Through a series of practical exercises and coding challenges, I developed core programming skills and learned how to create interactive programs that process data, perform calculations, and make decisions based on user input. 

---

## 🚀 Skills Demonstrated

### 🔤 Variables & Data Types
- Created and used variables to store data
- Worked with strings, integers, floats, and booleans
- Applied type casting to convert data between different formats

### 💬 User Interaction
- Used `print()` to display information and results
- Used `input()` to collect information from users
- Built simple interactive programs that respond to user actions

### 🧮 Calculations & Logic
- Performed mathematical calculations and formulas
- Created programs for:
  - Temperature conversions 🌡️
  - Area calculations 📐
  - Compound interest calculations 💰
  - Number and digit operations 🔢

### ✅ Decision Making
- Implemented `if`, `elif`, and `else` statements
- Built logic to:
  - Check if numbers are even or odd
  - Determine whether a number is positive, negative, or zero
  - Identify leap years
  - Validate user input

### 🔄 Loops & Iteration
- Used `for` loops to process repetitive tasks
- Used `while` loops to create menu-driven applications
- Generated sequences and repeated calculations efficiently

This challenge demonstrated problem-solving skills and control flow logic. 

### 📊 Python Problem Solving
Created programs to:
